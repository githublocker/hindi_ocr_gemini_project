# Abhishek_Hindi_English_OCR

A custom, offline-capable Hindi and English OCR tool built with Surya OCR and Streamlit.

## Installation

**Option 1: Install directly via pip (GitHub)**
1. Open your terminal.
2. Run the following command (replace with your actual GitHub URL):
   ```bash
   pip install git+[https://github.com/your-username/your-repo-name.git](https://github.com/your-username/your-repo-name.git)
Option 2: Clone and Install

Clone the repository:

Bash
git clone [https://github.com/your-username/your-repo-name.git](https://github.com/your-username/your-repo-name.git)
Navigate into the project folder:

Bash
cd your-repo-name
Install the required dependencies:

Bash
pip install -r requirements.txt
Usage
Open your terminal.

Start the interface by running:

Bash
python -m streamlit run app.py
A local URL will appear in your terminal. Click it or let it automatically open in your web browser.

Upload an image to the web interface.

Review the extracted text in the text area.

Make any necessary corrections to the text and click Save to Dataset to log it for future model training.
